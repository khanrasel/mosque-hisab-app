# মসজিদ হিসাব (Mosque Hisab)

বাংলা ভাষার একটি সাধারণ Android অ্যাপ—মসজিদের আয়, ব্যয়, দান/অনুদান এবং মোট হিসাব স্থানীয় SQLite ডাটাবেসে সংরক্ষণ করে।

## সুবিধা
- আয়, ব্যয় ও দান/অনুদান যোগ করা
- তারিখ, ধরন, বিবরণ ও টাকার পরিমাণ সংরক্ষণ
- মোট আয়, মোট ব্যয় ও বর্তমান ব্যালেন্স দেখা
- সাম্প্রতিক লেনদেনের তালিকা
- ডেটা ফোনেই থাকে; ইন্টারনেট প্রয়োজন নেই

## APK তৈরি
Android Studio-তে এই ফোল্ডারটি খুলুন, Gradle sync শেষ হলে **Build > Build APK(s)** নির্বাচন করুন।

GitHub Actions workflow-ও দেওয়া আছে। রিপোজিটরিতে পুরো প্রজেক্ট আপলোড করলে Actions থেকে Debug APK artifact পাওয়া যাবে।

> এটি একটি প্রাথমিক অফলাইন সংস্করণ। ডেটা ব্যাকআপ/রিস্টোর, একাধিক ব্যবহারকারী এবং PDF/Excel রিপোর্ট এখনো অন্তর্ভুক্ত নয়।
